
# 🎲 Manch Tak | منچ تک

بازی آنلاین چندنفره منچ برای اندروید با طراحی مدرن، رقابت آنلاین و امکانات اجتماعی.

## مشخصات پروژه

- نام پروژه: منچ تک
- نام انگلیسی: Manch Tak
- پلتفرم هدف: Android
- موتور بازی: Unity
- زبان برنامه‌نویسی: C#
- زبان رابط کاربری: فارسی و راست‌چین (RTL)

## میدان‌های مسابقه

### میدان آزادی
- ظرفیت: ۴ بازیکن
- هزینه ورود: ۵۰ سکه
- جایزه برنده: ۵۰۰ سکه

### میدان تجریش
- ظرفیت: ۲ بازیکن
- هزینه ورود: ۵۰ سکه
- جایزه برنده: ۲۰۰ سکه

## قوانین اقتصادی

- هنگام ورود به مسابقه فقط ۵۰ سکه کسر می‌شود.
- بازنده جریمه سکه‌ای اضافی ندارد.
- انصراف حین بازی جریمه سکه‌ای اضافی ندارد.
- جایزه فقط به برنده تعلق می‌گیرد.
- تراکنش‌ها باید در سمت سرور معتبر و قابل پیگیری باشند.

## سیستم پیشرفت

- هدیه ثبت‌نام: ۵۰۰ سکه و ۵۰۰ الماس
- XP برنده: ۱۳۸
- XP بازنده: ۵۰
- حداکثر سطح: ۲۰۰

## امکانات برنامه

- بازی آنلاین دونفره و چهارنفره
- بیش از ۲۰ مدل تاس
- ۶ تم مختلف صفحه بازی
- پروفایل دخترانه و پسرانه
- دوستان و چت خصوصی
- استیکر و پیام داخل بازی
- سیستم سطح، رتبه و جوایز
- پنل مدیریت
